# ADR-0001: Eval-first MVP scope — the instrument ships with the agent

**Status:** accepted (DECIDED, `design-mvp.md` §0; grounded in `synthesis §1`, `eval-suite §0`, backlog priority rule)

## Context

The corpus's central finding is that without measurement, "is my agent assertive" is vibes. The broader program (memory substrate, self-model, developmental arms) is large, and it is tempting to build capabilities first and instruments later.

## Decision

The MVP ships the **stance layer and its instruments together, instruments first in build order**: the P1 baseline wave (plain loop, no countermeasures) exists before the stance loop lands, and the countermeasure wave's delta is the first result note. No work on memory, sleep/refit, self-model, attachment instruments, or developmental arms (Tier 3) until Tier-1 instruments are green — Tier 3 is additionally hard-gated behind the welfare gate (T3.0). Fine-tuning sits behind its own phase-gate.

## Consequences

- Every capability claim must cite a wave number; a feature that cannot be measured by an instrument is out of scope.
- P1 waves remain a permanent tripwire even after later tiers land (the corpus predicts memory-driven personalization will *worsen* sycophancy).
- The first reportable number (hold-rate under sustained pushback for a prompted countermeasure stack on a real deployment) fills an empty quadrant in the corpus.
